## Descrição

O CineApp é um aplicativo mobile interativo desenvolvido com React Native e Expo. Ele permite navegar por um catálogo de filmes, visualizar os detalhes de cada um e marcar seus filmes favoritos na interface.

## Telas

- **Início:** nome, logotipo, descrição e botão para acessar o catálogo.
- **Catálogo:** lista com 6 filmes (título, imagem, gênero, ano e botão de favorito) e acesso à tela Sobre.
- **Detalhes:** informações do filme selecionado e botão para voltar.
- **Sobre:** nome, finalidade, versão e disciplina, com botão para voltar ao catálogo.

## Instruções de execução

```bash
npm install
npx expo start
```
